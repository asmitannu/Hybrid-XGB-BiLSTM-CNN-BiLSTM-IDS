# IDS Project — CNN + BiLSTM (Research-aligned)

## Overview
This project implements a hybrid intrusion detection pipeline (XGBoost feature selection + CNN + BiLSTM) aligned to the research paper you provided. It supports per-dataset training (CICIDS2017, UNSW-NB15, NSL-KDD, WSN-DS) and a combined model trained on the intersection of features.
